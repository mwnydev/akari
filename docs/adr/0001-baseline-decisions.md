# 0001 基线技术决策以开发计划 v3 为准

- 状态：已采纳
- 日期：2026-10-19

## 背景

[开发计划 v3](../plan-v3.md) 第 1、3、17 节已经定下语言、链、钱包、费用和 gas 规则。为避免在 ADR 里重复一遍再出现两份不一致的定义，基线决策只在计划中维护。

## 决定

- 计划第 1 节「关键决策一览」和第 17 节「已定」各条即为已采纳的基线决策。
- 之后任何偏离计划的决定、计划里的待决事项定案，都单独写一份 ADR，并在计划对应位置注明 ADR 编号。
- 版本以第 3 节为基线，实际锁定版本以 `Cargo.lock`、`pnpm-lock.yaml`、`foundry.toml`、`rust-toolchain.toml` 为准。

## 后果

计划文档成为受版本控制的规格；修改计划需走 PR。
