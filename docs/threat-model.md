# 资金与账号威胁分析（v0，第 1 周）

依据：[plan-v3](plan-v3.md) 第 5、6、9、11 节。每个涉及资金、账号、权限的任务开工前，在本文件对应小节补充或引用条目（`T-xx`），PR 说明里写明影响到的条目。

## 资产

| 编号 | 资产 | 价值 | 只有谁能动 |
| --- | --- | --- | --- |
| A1 | 合约中托管的 USDT | 全部订单金额 | 合约规则（买家 / 卖家 / 仲裁 Safe 的 `resolve` 只能分给双方） |
| A2 | 卖家保证金池 | 保证金总额 | 卖家（未锁定部分）、`resolve`（锁定部分只能赔给买家） |
| A3 | 用户钱包余额 | 用户自有 | 钱包 Passkey；恢复码 48 小时延迟 |
| A4 | 金库 / 运营 / 薪资 Safe | 平台收入 | 各自签名设备 |
| A5 | Paymaster 押金 + 代发器热钱包 ETH | 约 2 周 gas | forum-sponsor 私钥（泄露最多耗尽） |
| A6 | 订单聊天与证据 | 仲裁依据 | 只追加 + 哈希链 + R2 加密副本 |
| A7 | 会话与账号 | 论坛身份 | 邮箱验证码；敏感操作另需 Passkey |
| A8 | 拍卖成交签名私钥 | 成交证明 | forum-sponsor |

## 攻击者

| 编号 | 攻击者 | 能力假设 |
| --- | --- | --- |
| E1 | 普通恶意用户 / 骗子 | 注册任意账号、调用任意公开合约函数、刷接口 |
| E2 | 邮箱被盗的用户 | 能登录论坛，没有钱包 Passkey |
| E3 | Passkey 同步账号（iCloud / Google）被盗 | 能在自写页面上请求钱包签名 |
| E4 | 论坛主站 XSS / 服务器被完全攻破 | 改主站页面、读写数据库、拿到服务器上全部密钥 |
| E5 | 恶意或被盗的内部人员（版主 → 站长） | 后台权限、可能持有一个 Safe 签名设备 |
| E6 | 域名或 Cloudflare 账号被盗 | 改 DNS、改 Pages 部署 |
| E7 | 链层故障 | 排序器停摆、RPC 返回错误或回滚数据、USDT 冻结地址 |

## 残余风险（接受并公开说明）

- 合约未知漏洞：审计、单笔上限 1000 USDT、灰度放量、漏洞赏金。
- T-13：P1 前只能靠通知止损。
- 中心域名丢失：恢复码兜底，用户需自付少量 ETH。
